# React E2 Competency Program

This folder contains a curriculum and resources to take a developer from intermediate React skills to an "E2" (expert) competency level covering architecture, performance, testing, TypeScript, advanced hooks, patterns, and full-stack integration.

Contents:
- `curriculum.md` — topics and objectives
- `roadmap.md` — suggested weekly schedule
- `exercises.md` — hands-on tasks and project ideas
- `assessments.md` — rubrics, interview questions, and capstone project
- `examples/react-skeleton/` — starter app for exercises
