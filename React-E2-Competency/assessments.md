# Assessments and Rubrics

Assessment types:

- Weekly quizzes (concept checks)
- Coding challenges (take-home)
- Pair-programming session (live)
- Capstone project review

Rubric highlights for capstone:

- Architecture (30%): clear separation of concerns, scaling considerations
- Code Quality & Tests (25%): readable, tested, CI integration
- Performance & Reliability (20%): profiling, caching, error handling
- UX & Accessibility (15%): responsive, accessible components
- Documentation & Dev Experience (10%): README, setup scripts

Assessment examples and scoring

- Weekly quiz: 10 multiple-choice questions (auto-graded). Passing: 80%.
- Coding challenge: 3-5 hour take-home task. Scored on correctness, design, and tests.
- Pair-programming: 45-minute session; focus on communication, debugging, and architecture.

Capstone expectations:

- Deliverables: source code in a repo, README with setup, recorded demo (5-10 minutes), and test suite.
- Passing criteria: overall score >= 75% with no critical security or accessibility failures.
