# Curriculum: React E2 Competency

Goal: develop expert-level skills across React, TypeScript, performance, testing, state management, architecture, and full-stack integration.

Core Modules:

1. Advanced JavaScript & TypeScript
   - Deep dive into closures, event loop, memory model
   - TypeScript advanced types, generics, mapped types

2. Advanced React Patterns
   - Hooks internals, custom hooks, render props, higher-order components
   - Compound components, controlled vs uncontrolled patterns

3. State Management at Scale
   - Context + useReducer, Redux Toolkit, Zustand, Jotai
   - Normalization, optimistic updates, caching strategies

4. Performance & Optimization
   - React rendering behavior, memoization, virtualization
   - Profiling, code-splitting, lazy loading, web vitals

5. Testing & Reliability
   - Unit tests, integration tests, E2E (Playwright/Cypress)
   - Contract testing, mocking model responses, CI pipelines

6. Architecture & Patterns
   - Micro-frontends, module federation, monorepo strategies
   - Backend-for-frontend, API design for AI integration

7. Full-stack Integration
   - Node.js & Next.js patterns, Java backends when needed
   - Auth, security, observability, deployment

8. Capstone Projects
   - Build a production-like app integrating an AI agent, caching, auth, and tests

Appendix: Learning outcomes per module

- Advanced JS & TS: write type-safe libraries, reason about async internals, optimize for memory and speed.
- Advanced React Patterns: design reusable component APIs, avoid common anti-patterns, and implement accessible components.
- State Management: choose appropriate store for scale, implement optimistic updates and reconciliation strategies.
- Performance: identify render storms, reduce re-renders, and implement virtualization for large lists.
- Testing: achieve high coverage on business logic, write reliable E2E flows, and mock external model calls for CI.
