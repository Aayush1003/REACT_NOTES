## 🚀 Quick Start

**Prerequisites:**
- Node.js 16+ (LTS recommended)
- npm, yarn, or pnpm
- Basic JavaScript knowledge

**Create a new React project:**

```bash
# Using Vite (recommended)
npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev

# Or using Create React App (older)
npx create-react-app my-app
cd my-app
npm start
```

## 🎯 Tips for Success

1. **Code Along**: Don't just read — type out examples in your editor.
2. **Experiment**: Modify examples to see what breaks and why.
3. **Check Dependencies**: Use ESLint plugin `react-hooks/exhaustive-deps`.
4. **Use DevTools**: Install React Developer Tools browser extension.
5. **Read Error Messages**: React's warnings are helpful — read them carefully.
6. **Build Projects**: Apply concepts in small projects.
