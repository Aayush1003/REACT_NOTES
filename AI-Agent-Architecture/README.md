# AI Agent Architecture for React Projects

This folder documents how AI agents can be integrated into React-based projects and provides starter skeletons for React, Node.js, Next.js, and Java backends.

Structure:
- `architecture.md` — integration patterns, responsibilities, and data flow.
- `quickstart.md` — steps to run example skeletons.
- `examples/` — minimal example skeletons for frontends and backends.

Next steps: open `architecture.md` to learn patterns and `examples/` to try skeletons.
